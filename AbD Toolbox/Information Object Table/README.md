# Information Object Table

## Overview

The Information Object Table is a practical tool within the Archiving by Design (AbD) Toolbox. It provides a central inventory of information object groups and types relevant to an AbD project, together with their AbD-related attributes.

The table supports the identification, analysis and documentation of information objects throughout the project lifecycle, from initiation and design to implementation and operations.

As the project progresses, information objects and their attributes can be refined and expanded. The table also helps document requirements, design decisions and unresolved risks, providing a shared reference for project stakeholders.

## How to use

Start with the Guidelines for using the Information Object Table. Use the Excel template to register relevant information object groups and types, and consult the Possible attributes document for suggested attributes and their priorities across project phases.

The template and attributes can be adapted to national, organisational and project-specific requirements.
